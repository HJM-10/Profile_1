# Profile_1

## Cinematic portfolio

A line-drawn name reveal leads into an engraved About section, expandable project stories, and a contact section.

## Run locally

Use Node.js 20.9 or later.

```sh
npm ci
npm run dev
```

Open http://127.0.0.1:3111.

For a production preview, run `npm run build` followed by `npm run start`.
