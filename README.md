# Profile_1

## Cinematic portfolio

A line-drawn opening leads into an engraved About section, a dark services section, one Projects gallery, and a contact finale.

The Projects section presents 24 visual covers in four scroll-driven chapters. The hexagonal picker takes visitors directly to a project in the gallery, and the dropdown reaches every project. Select a cover to read its details. Reduced-motion users get a visual grid. The charcoal palette carries from the opening through the project gallery and contact section.

PhishScan, SialMail, Personal AI Agent, UMT LMS, and the certificate tools use original frontend captures. PhishScan shows sample messages. NeuroSpatial-OS, GRIDGUARD PK, the office approval proposal, and used-car price prediction use concept artwork.

## Run locally

Use Node.js 20.9 or later.

```sh
npm ci
npm run dev
```

Open http://127.0.0.1:3111.

For a production preview, run `npm run build` followed by `npm run start`.
